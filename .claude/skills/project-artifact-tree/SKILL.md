# 통합문서 트리 등록 (공통)

## 통합문서 찾기
- 프로젝트 지침 또는 저장소 CLAUDE.md 의 "통합문서:" 줄에 있는 링크를 쓴다.
- 지침 · CLAUDE.md 가 전용 스킬(suwon-artifact-tree, photo-artifact-tree 등)을 지정하면 그 스킬을 따르고 이 스킬은 쓰지 않는다.
- 링크가 없으면 사용자에게 묻거나 new-dev-project 스킬로 셋팅하자고 제안한다.
- 이 스킬의 원본 = 계정 스킬. 각 저장소 `.claude/skills/project-artifact-tree/SKILL.md` 는 사본이다. 고칠 때는 계정 스킬을 고치고 저장소 사본을 맞춘다.

## 언제
- 아티팩트를 새로 만든 직후 (Docs, Design, Slides, Sheets, Dashboard, HTML 페이지)
- 파일(.md, .html, .png 등)을 만들어 사용자에게 보낸 직후
- 기존 아티팩트의 새 버전이 나와 "최신" 표시가 바뀔 때
- 개발 시작 · 머지 완료 때 (아래 "할 일 상태 옮기기")
- 채팅 · Code 에서 작업 하나를 끝냈을 때 (아티팩트가 없어도): 작업기록 > 오늘 탭에 한 줄 (한 일 | 결과, Code 는 PR 번호도)
- 채팅을 시작할 때: 저장소 PROGRESS-LOG.md 에 "트리 등록 필요 · 트리 반영 필요"가 남아 있으면 먼저 통합문서에 반영하고, 반영한 항목은 답변에 한 줄로 알린다 (PROGRESS-LOG.md 비고는 Code 가 다음 작업 때 "반영 끝"으로 고침)
- 채팅을 마칠 때: 이번 채팅에서 만든 것 목록과 트리를 대조해 빠진 것 등록
- 사용자가 "트리 등록"이라고 할 때

등록은 만든 그 답변 안에서 바로 한다. 채팅 보관 때까지 미루지 않는다.

## 어디에 (기본 트리)
| 만든 것 | 탭 |
|---|---|
| 결정 · 계획 · 데이터 · 조사 문서 | 자료 > 개발 문서 |
| 화면 시안 · 목업 (Design) | 자료 > 화면 시안 (최신이 맨 위) |
| 새 할 일 | 해야할일 > 사용자가 할 일 · 개발 (Claude) |
| 그날 한 일 | 작업기록 > 날짜 탭 "MM/DD (요일)" — 없으면 만든다 |

문서에 다른 탭(브랜드 등)이 더 있으면 내용이 맞는 탭을 쓴다. 맞는 탭이 없으면 임의로 만들지 말고 자료 아래에 새 탭을 만들지 묻는다.

## 방법
1. 통합문서를 읽어 탭 목록을 확인한다.
2. 대상 탭의 표를 읽는다. 보통 2열: 이름(링크) | 내용 한 줄.
3. 행 추가: 첫 칸 = 제목에 링크, 둘째 칸 = 날짜 + 한 줄 설명. 화면 시안 표는 헤더 바로 아래(맨 위)에, 다른 표는 맨 아래에.
4. "— | 아직 없음" 같은 빈 자리 행만 있으면 그 행을 바꾸어 채운다.
5. 같은 링크가 이미 있으면 행을 늘리지 않고 설명만 고친다.
6. 저장소(docs/)로 옮겨진 문서는 링크를 저장소 주소로 바꾸고 설명에 "(아티팩트 = 이력)"을 붙인다.
7. 답변 끝에 한 줄로 위치를 알린다. 예: "통합문서 > 자료 > 개발 문서에 등록했어요."

## 할 일 상태 옮기기 (요청 없이 자동)
- 개발 시작(새 브랜치 · 분기 시작): 해야할일의 해당 행(새 메모 · 원문 메모 포함)을 지우고 '진행 중'으로 옮긴다.
- 완료(CLAUDE.md 가 정한 기준: 머지 + 배포 · 헬스 UP, 또는 머지 + 실행 확인): '진행 중' 행을 지우고 '작업기록 > MM/DD (요일)' 탭 표 맨 아래로 옮긴다 (탭이 없으면 만든다).
- 이 옮기기는 아래 "지우지 않는다" 의 예외다.

## 통합문서를 못 열 때 (Claude Code 등 Docs 연결 없음)
- PROGRESS-LOG.md 비고에 "트리 등록 필요: <제목> · <링크> · <탭>"을 남긴다. (할 일 상태 옮기기도 "트리 반영 필요: <할 일> → <상태>"로)
- 사용자에게 한 줄 안내: "채팅에서 '트리 등록'이라고 말하면 반영돼요."
- 채팅 쪽은 "트리 등록" 요청을 받으면 PROGRESS-LOG.md 의 해당 항목을 읽어 반영한다.

## 하지 않는 것
- 비밀값 · 토큰 · 개인정보가 보이는 캡처 링크는 넣지 않는다.
- 요청 없이 기존 행의 문구를 고치거나 지우지 않는다. (예외: 위 "할 일 상태 옮기기")
