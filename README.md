# Job-Catch

개인 구직용 채용공고 알림 프로젝트입니다.

관심 직무의 채용공고를 하루 1회 조회해서, 이미 알린 공고는 빼고, 새 공고만 본인에게 알림으로 보냅니다. 공고를 일일이 찾아다니는 시간을 줄이는 것이 목표입니다.

## 범위

- **비상업 개인 프로젝트**입니다. 결과는 본인만 보며, 수집한 공고를 재배포하거나 다른 서비스에 게시하지 않습니다.
- 공고마다 제목, 회사, 마감일, 원문 링크 정도만 다루고, 지원은 원문 사이트에서 직접 합니다.
- 조회는 하루 1회 이하로 제한합니다.
