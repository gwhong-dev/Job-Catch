# Job-Catch

개인 구직용 채용공고 알림 프로젝트입니다.

사람인과 잡코리아에서 내 조건에 맞는 새 공고만 골라, 매일 아침 메일 한 통으로 받습니다. 메일은 휴대폰에서 읽기 좋은 카드 모양이고, 카드를 누르면 원문 공고로 갑니다. 공고를 일일이 찾아다니는 시간을 줄이는 것이 목표입니다.

## 무엇을 해 주나요

- **두 갈래 이상의 검색**: 예를 들어 "기구설계는 사람인에서 신입·경력", "개발 직무는 잡코리아에서 신입"처럼 갈래마다 키워드 · 사이트 · 경력 조건을 따로 둡니다.
- **공통 조건으로 거르기**: 학력(내 학력으로 지원 가능한 공고만), 내 경력으로 맞출 수 있는 경력 공고만, 제외 단어 · 회사 · 고용형태.
- **통근 시간**: 공고 상세 페이지의 근무지 주소로 집에서 가는 대중교통 시간을 구해(카카오맵 API) 60분 이내만 남깁니다. 60~75분은 "통근 확인" 표시로 남깁니다. 카카오 키가 없으면 지역 목록으로 대신 거릅니다.
- **이미 보낸 공고는 빼고**, 마감 7일 이내 공고는 예전에 보낸 것도 "마감 임박"으로 다시 알려 줍니다.
- **조용한 실패 방지**: 사이트 구조가 바뀌어 한 사이트가 0건이면 메일 맨 위에 경고가 붙습니다.
- **세부 묶음과 요약**: 갈래 안을 `groups` 설정(예: 기구설계 / 장비설계 / 설비설계)으로 나누고, 메일 맨 위에 건수 목차를 둡니다. 카드에는 근무지 주소, 상세 본문의 주요업무 첫 부분(📝), 자격요건의 필수조건(✅, 우대는 빼고 보여 주기만 함), 설계 툴 · 분야 · 개발 기술 태그(Creo, SolidWorks, 반도체, Spring 등)를 붙입니다. 묶음 안에서는 통근 시간이 짧은 공고가 위로 옵니다.
- **AI 요약 · 적합도 (선택, 무료)**: `GEMINI_API_KEY` 가 있으면 메일에 실리는 카드마다 Gemini Flash-Lite(무료 등급)가 본문 글자와 **공고 이미지**까지 읽어 📝 업무 요약 · ✅ 필수조건을 만들고, 갈래마다 적어 둔 기준(`fit`)으로 🎯 적합도(상 · 중 · 하)와 이유 한 줄을 붙입니다. 본문이 이미지뿐인 공고도 요약이 나옵니다. 적합도는 **표시만** 하고 공고를 거르거나 순서를 바꾸지 않습니다. 키가 없거나 AI 호출이 실패하면 지금처럼 규칙으로 뽑은 요약을 쓰고, 한도 초과 · 키 문제로 중간에 멈추면 메일 맨 위에 경고가 붙습니다.

## 범위

- **비상업 개인 프로젝트**입니다. 결과는 각자 자기에게만 메일로 보내며, 수집한 공고를 재배포하거나 다른 서비스에 게시하지 않습니다.
- 공고마다 제목, 회사, 마감일, 근무지, 원문 링크 정도만 다루고, 지원은 원문 사이트에서 직접 합니다.
- 조회는 하루 1회, 검색어당 최대 2페이지, 요청 사이 2초 이상 쉬며 합니다. 상세 페이지는 처음 보는 후보 공고만 하루 최대 150건(15분 안) 읽고, 넘친 공고는 다음 날 다시 읽습니다 (마감 7일 안 공고는 그날 지역 목록으로 판정해 싣습니다).
- AI 요약을 켜면 메일에 실리는 카드의 공고 이미지만 내려받습니다 (공고당 최대 6장, 장 사이 1초 쉼). 제외되거나 "외 N건" 으로 빠진 공고에는 AI 를 부르지 않습니다.
- 사람에게 보여 주는 검색 · 공고 페이지를 읽습니다. 두 사이트의 robots.txt 는 일반 접속에 이 경로를 막지 않습니다 (2026-11 확인).

## 내 저장소에서 쓰기 (GitHub Actions, 무료)

PC 를 켜 두지 않아도 GitHub 서버가 매일 06:30(한국 시간)에 돌려서 7시 무렵 메일이 옵니다.

1. **이 저장소를 fork** 합니다.
2. **Gmail 앱 비밀번호 만들기**: Google 계정에 2단계 인증을 켠 뒤 <https://myaccount.google.com/apppasswords> 에서 만듭니다 (16자리).
3. **(선택) Gemini API 키 만들기**: <https://aistudio.google.com/apikey> 에서 만듭니다. 결제 수단을 등록하지 않으면 무료 등급이고 요금이 나가지 않습니다. 무료 등급에서 보낸 내용(공고 본문 · 이미지 · `fit` 기준)은 Google 이 서비스 개선 · 학습에 쓸 수 있으니, `fit` 에는 이름 · 집 주소 · 학력 같은 개인정보를 쓰지 마세요.
4. **(선택) 카카오 REST API 키 만들기**: <https://developers.kakao.com> 에서 앱을 만들고, 앱 설정에서 카카오맵 사용을 켠 뒤 REST API 키를 복사합니다. 무료 쿼터(대중교통 경로 하루 1,000건, 주소 변환 하루 100,000건)는 계정의 첫 번째 앱에만 적용됩니다.
5. 내 저장소 **Settings → Secrets and variables → Actions** 에 등록합니다.

   | 종류 | 이름 | 값 |
   |---|---|---|
   | Secret | `JOBCATCH_CONFIG` | `config.example.toml` 을 내 조건으로 고친 내용 전체 |
   | Secret | `GMAIL_USER` | 보내는 Gmail 주소 |
   | Secret | `GMAIL_APP_PASSWORD` | 2번의 앱 비밀번호 |
   | Secret | `MAIL_TO` | 받을 메일 주소 (보통 자기 주소) |
   | Secret | `KAKAO_REST_KEY` | 4번의 키 (없으면 통근 계산 없이 지역 목록만 씀) |
   | Secret | `GEMINI_API_KEY` | 3번의 키 (없으면 AI 없이 규칙 요약만 씀) |

   검색 기준도 **Secret** 에 둡니다. Variable 에 넣으면 공개 저장소의 실행 로그에 그 내용이 그대로 찍힙니다. Secret 은 저장 뒤 다시 볼 수 없으니, 원본은 내 PC 의 `config.toml` 에 두고 고칠 때마다 Secret 을 통째로 다시 붙여 넣으세요.
6. **Actions 탭에서 워크플로 켜기**: fork 한 저장소는 예약 실행이 기본으로 꺼져 있습니다. `daily-mail` 을 고르고 **Run workflow** 로 한 번 돌려 메일이 오는지 확인합니다.
7. **첫 실행 로그 확인**: "수집 · 메일 발송" 단계 로그에서
   - env 값이 모두 `***` 로 가려져 있는지
   - 두 사이트 수집 건수가 0 이 아닌지
   - 카카오 키를 넣었다면 "통근 계산 N건" 이 0 이 아닌지 ("경고: 통근 계산 꺼짐 (집 주소 없음)" 이면 설정의 `home_address` 가 비어 있는 것)
   - Gemini 키를 넣었다면 "AI 요약 N건" 이 0 이 아닌지 ("AI 요약 꺼짐" 이면 키가 안 넘어간 것). 실패가 있으면 `실패 10 (HTTP 500: 6 · 시간 초과: 4)` 처럼 원인별 건수가 붙습니다

### 알아 둘 것
- 공개 저장소의 예약 워크플로는 저장소에 60일 동안 활동이 없으면 GitHub 가 자동으로 끕니다. 메일이 안 오면 Actions 탭에서 다시 켜 주세요.
- **메일은 하루(한국 시간) 한 번만** 보냅니다. GitHub 예약 실행은 몇 시간 늦거나 한 번 더 돌기도 해서, 그날 발송에 성공한 기록(`data/sent.json`, 날짜만)이 있으면 수집도 하지 않고 "오늘 이미 보냄 — 건너뜀" 만 남깁니다. 발송에 실패한 날은 다음 실행이 다시 보냅니다. 같은 날 한 번 더 돌리려면 **Run workflow** 에서 "오늘 이미 보냈어도 다시 보내기" 를 켜세요. 아침 메일의 공고는 이미 보낸 것으로 기록돼 있어, 그 뒤에 올라온 새 공고만 실립니다 (없으면 "새 공고 없음"). 손 실행은 **main 브랜치**에서 하세요: 다른 브랜치에서 돌리면 기록이 그 브랜치 캐시에 저장돼 main 의 예약 실행이 보지 못합니다.
- 보낸 기록(`data/seen.json`, 공고 제목 · 회사)은 Actions 캐시에 있습니다. Settings → Actions → General 에서 외부 기여자의 워크플로 실행에 승인이 필요하도록 두세요 (기본값).
- 메일에 다 못 실은 "외 N건" 도 보낸 것으로 기록됩니다. 갈래당 카드 수(`max_cards_per_track`)를 늘리면 더 많이 받습니다.

공개 저장소의 실행 로그는 누구나 볼 수 있어서, 로그에는 건수만 남기고 키워드 · 공고 제목 · 설정 내용은 출력하지 않습니다. **실제 검색 기준(학력 · 경력 · 집 주소)은 저장소에 커밋하지 마세요.**

## 로컬에서 시험

```bash
pip install -r requirements.txt
cp config.example.toml config.toml   # 내 조건으로 고치기 (config.toml 은 커밋되지 않음)
python run.py --dry-run              # 메일 대신 output/mail_<날짜>.html 로 미리보기
python -m pytest -q                  # 테스트
```

`--dry-run` 없이 돌리면 환경변수 `GMAIL_USER`, `GMAIL_APP_PASSWORD`, `MAIL_TO` 로 메일을 보내고 `data/seen.json` 에 보낸 기록, `data/sent.json` 에 보낸 날짜를 남깁니다. 같은 날 다시 보내려면 `python run.py --force`. `KAKAO_REST_KEY` 를 넣으면 통근 시간도 계산하고, `GEMINI_API_KEY` 를 넣으면 AI 요약 · 적합도도 붙습니다.

## 구조

| 파일 | 역할 |
|---|---|
| `jobcatch/config.py` | 검색 기준 읽기 (`JOBCATCH_CONFIG` → `config.toml`) |
| `jobcatch/saramin.py`, `jobcatch/jobkorea.py` | 검색 페이지 · 상세 페이지 읽기 |
| `jobcatch/filters.py` | 학력 · 경력 · 지역 · 제외 조건으로 분류 |
| `jobcatch/commute.py` | 카카오 주소 변환 · 대중교통 시간 |
| `jobcatch/summary.py` | 규칙 방식 요약 · 필수조건 · 태그 (AI 가 없거나 실패할 때) |
| `jobcatch/ai.py` | Gemini 로 카드 요약 · 필수조건 · 적합도 (이미지 포함) |
| `jobcatch/digest.py` | 수집 → 분류 → 새 공고 / 마감 임박 묶기 |
| `jobcatch/history.py` | 보낸 공고 기록 · 그날 발송 날짜 |
| `jobcatch/mail.py` | 메일 HTML · Gmail 발송 |
| `.github/workflows/daily.yml` | 매일 06:30 KST 실행 |
